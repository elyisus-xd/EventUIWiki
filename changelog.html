Changelog

Registro de cambios entre versiones de EventUI. Cada entrada documenta bugs corregidos, mejoras y nuevas features.

v1.0.1

2025 — En progreso latest
Sistema de Tooltips Avanzados
  • NEW Nuevos tipos de sección de receta: FURNACE_RECIPE, SMITHING_RECIPE, ANVIL_RECIPE, BREWING_RECIPE — cada uno con su textura de interfaz vanilla incluida en el mod
  • NEW CUSTOM_RECIPE — tipo genérico donde el admin define su propia textura y las coordenadas X,Y de cada slot en el YAML, para recetas de mods
  • NEW Soporte para override de textura de frame desde el YAML con section_1_recipe_frame — compatible con resource packs
  • NEW RecipeCache — las recetas se cachean tras la primera búsqueda, eliminando búsquedas O(n) en el RecipeManager cada frame
  • NEW inventory_preview — overlay oscuro en ingredientes que el jugador no tiene en su inventario (opcional, activar con inventory_preview: true)
  • NEW show_tooltip_background — controla si se muestra el cuadro morado/negro del tooltip. Poner en false para mostrar solo la receta sin fondo
  • NEW Cycling de items en todos los tipos de receta — múltiples items separados por coma se rotan automáticamente cada segundo
  • IMPROVED show_grid_frame ahora funciona correctamente en Shaped/Shapeless (mostraba el frame aunque estuviera en false)
  • FIX FURNACE_RECIPE, SMITHING_RECIPE, ANVIL_RECIPE y BREWING_RECIPE no se reconocían como SectionType válidos (el catch del valueOf hacía fallback silencioso a RECIPE)
Sistema de guardado de progreso
  • NEW Guardado inmediato al completar un objetivo, evento, o auto-inicio — ya no hay que esperar al auto-save periódico para eventos importantes
  • NEW Guardado inmediato en cambios de estado desde /ev y desde el bridge
  • IMPROVED Auto-save periódico reducido de 5 minutos a 2 minutos
  • IMPROVED Sistema de throttle/coalescing por jugador — si llegan múltiples solicitudes de guardado juntas, se agrupan en una sola escritura
  • FIX Validación al cargar playerdata: estado inválido → fallback a AVAILABLE, evento inexistente → ignorado con warning, values fuera de rango → clamping
Sistema de mensajería del mod
  • FIX EVENT_RELOAD_NOTIFICATION era sobreescrito silenciosamente por EventViewModel (Map<MessageType, MessageHandler> hacía put() en vez de add()) — la reconstrucción de UI tras /ev reload nunca se ejecutaba
  • IMPROVED MessageHandler cambiado a Map<MessageType, List<MessageHandler>> con CopyOnWriteArrayList — múltiples handlers por tipo de mensaje
  • NEW removeHandler(type, handler) para remover un handler específico sin afectar a los demás (patrón MessageHandler[] handlerRef para auto-remoción)
Caché de UI en el cliente
  • FIX cachedUIMode y cachedScreenId (campos static) sobrevivían entre reconexiones — al reconectar a un servidor con UI distinta, el cliente seguía mostrando la UI anterior
  • FIX Cambiar screenId en config.yml en caliente no actualizaba la UI en el cliente porque el handler de EVENT_RELOAD_NOTIFICATION era sobreescrito (ver fix de MessageHandler arriba)
  • NEW invalidateCache() llamado automáticamente en ClientPlayConnectionEvents.JOIN y DISCONNECT — cada conexión nueva siempre pide el modo de UI fresco
Objetivos y tracking
  • FIX BREW_POTION: el handler de InventoryClickEvent no detectaba pociones completadas cuando el jugador cerraba la GUI antes de que terminara el brewing — migrado a BrewEvent de Bukkit
  • FIX tryAutoStart() tenía la lógica de retorno completamente invertida en las tres ramas — afectaba a TODOS los tipos de objetivo, haciendo que los eventos IN_PROGRESS siempre se saltaran en processAction()
  • FIX /ev abandon conectado al switch de comandos (existía el handler pero nunca se llamaba — el cliente enviaba "abandon_event" sin el event_id)
  • FIX Cliente enviaba action: "abandon_event" sin concatenar el event_id — ahora envía "abandon_event:{eventId}" como esperaba PluginEventBridge
Toolchain y build
  • FIX fabric-loom migrado de 1.8-SNAPSHOT a 1.12.7 (getDependencyProject() removido en Gradle 8.14+)
  • FIX Shadow plugin migrado de com.github.johnrengelman.shadow:8.1.1 a com.gradleup.shadow:9.4.2 (StubbedFileCopyDetails.mode removido en Gradle 8.14)

v1.0.0

2025 — Versión inicial
Lanzamiento inicial
  • NEW Primera versión pública de EventUI. Incluye el sistema completo de misiones con 21 tipos de objetivo, el motor de UI declarativa en YAML, el bridge de comunicación plugin-mod, y la UI hardcoded de referencia.
