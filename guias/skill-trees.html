Skill Trees

Los árboles de habilidades permiten a los jugadores desbloquear mejoras progresivas mediante puntos. Cada árbol puede tener ramas exclusivas, efectos de atributos y múltiples tipos de puntos.

Estructura de un árbol de habilidades

Los skill trees se definen como archivos .yml dentro de la carpeta plugins/EventUI/skills/.

skills/combat-tree.yml — estructura básica
id: "combat-tree"
display_name: "Árbol de Combate"
description: "Mejora tus estadísticas de combate"
point_type: "Puntos de Combate"

# Grupos exclusivos (opcional)
exclusive_groups:
  - id: "class_choice"
    name: "Clase de Combate"
    description: "Elige una especialización de combate"
    max_selections: 1
    branches:
      - id: "healer"
        name: "Aguante"
        nodes: ["vitality_1", "vitality_2", "regeneration"]
      - id: "assassin"
        name: "Asesino"
        nodes: ["attack_1", "attack_2", "attack_3"]

# Nodos del árbol
nodes:
  - id: "vitality_1"
    display_name: "Vitalidad I"
    description: "+1 corazon de vida máxima por nivel"
    icon: "minecraft:apple"
    max_level: 5
    cost_per_level: 1
    requires: []
    position:
      x: 0
      y: 0
    effects:
      - type: "attribute"
        attribute: "GENERIC_MAX_HEALTH"
        operation: "add"
        value_per_level: 2

Campos raíz

Campo Tipo Obligatorio Descripción
id String ✅ Sí Identificador único del árbol. Solo letras, números y guiones.
display_name String ✅ Sí Nombre visible en la UI. Acepta § para colores.
description String ✅ Sí Descripción del árbol de habilidades.
point_type String ✅ Sí Tipo de puntos usado por defecto en este árbol. Puede ser un alias (ej: "Puntos de Combate").
exclusive_groups Lista No Grupos de ramas exclusivas. Los jugadores seleccionan una rama por grupo.
nodes Lista ✅ Sí Lista de nodos que componen el árbol de habilidades.

Grupos exclusivos

Los grupos exclusivos permiten crear especializaciones mutuamente excluyentes. Un jugador solo puede seleccionar una rama por grupo.

Campo Tipo Descripción
id String Identificador único del grupo exclusivo.
name String Nombre visible del grupo en la UI.
description String Descripción del grupo exclusivo.
max_selections Número Máximo de ramas seleccionables en este grupo (usualmente 1).
branches Lista Lista de ramas disponibles en este grupo.

Estructura de una rama

Campo Tipo Descripción
id String Identificador único de la rama.
name String Nombre visible de la rama en la UI.
nodes Lista de IDs Lista de IDs de nodos que pertenecen a esta rama.
Los nodos en ramas no seleccionadas se bloquean automáticamente. El jugador debe seleccionar una rama antes de poder desbloquear nodos en ella.

Definición de nodos

Campo Tipo Obligatorio Descripción
id String ✅ Sí Identificador único del nodo dentro del árbol.
display_name String ✅ Sí Nombre visible del nodo en la UI.
description String ✅ Sí Descripción del efecto del nodo.
icon String ✅ Sí ResourceLocation del ítem usado como ícono (ej: "minecraft:apple").
max_level Número ✅ Sí Nivel máximo del nodo.
cost_per_level Número ✅ Sí Costo en puntos por nivel.
point_type String No Tipo de puntos específico para este nodo (sobrescribe el del árbol). Permite usar diferentes tipos de puntos en diferentes nodos del mismo árbol.
requires Lista No Lista de requisitos (nodos previos con niveles mínimos).
position Mapa ✅ Sí Coordenadas X/Y del nodo en el canvas del árbol.
effects Lista ✅ Sí Lista de efectos aplicados por el nodo.

Sistema de requisitos

Los nodos pueden tener requisitos de otros nodos. El jugador debe cumplir todos los requisitos para desbloquear el nodo.

Ejemplo de requisitos
requires:
  - node: "vitality_1"
    min_level: 5
  - node: "attack_1"
    min_level: 3
Campo Tipo Descripción
node String ID del nodo requerido.
min_level Número Nivel mínimo requerido del nodo.

Efectos de atributos

Los nodos aplican efectos a los atributos del jugador. Actualmente solo se soportan efectos de tipo attribute.

Ejemplo de efecto
effects:
  - type: "attribute"
    attribute: "GENERIC_MAX_HEALTH"
    operation: "add"
    value_per_level: 2
Campo Tipo Descripción
type String Tipo de efecto. Actualmente solo "attribute".
attribute String Atributo de Minecraft a modificar.
operation String Operación: "add", "multiply", "add_scalar", "add_percent".
value_per_level Número Valor aplicado por cada nivel del nodo.

Operaciones soportadas

Operación Descripción
add Suma el valor al atributo base.
multiply Multiplica el atributo por el valor.
add_scalar Suma un valor escalar al atributo.
add_percent Añade un porcentaje al atributo.

Atributos disponibles

Atributo Descripción
GENERIC_MAX_HEALTH Vida máxima
GENERIC_ATTACK_DAMAGE Daño de ataque
GENERIC_ARMOR Armadura
GENERIC_ARMOR_TOUGHNESS Resistencia de armadura
GENERIC_KNOCKBACK_RESISTANCE Resistencia al knockback
GENERIC_REGENERATION Regeneración de vida
GENERIC_STEP_HEIGHT Altura de salto automático
GENERIC_SAFE_FALL_DISTANCE Distancia de caída segura
PLAYER_SNEAKING_SPEED Velocidad al agacharse
GENERIC_LUCK Suerte

UI del árbol de habilidades

Para mostrar un árbol de habilidades en una UI, usa el elemento SKILL_TREE:

uis/skills-screen.yml
- id: "combat_tree"
  type: SKILL_TREE
  x: 50
  y: 120
  width: 900
  height: 500
  properties:
    tree_id: "combat-tree"
    node_size: "60"
    node_spacing_x: "110"
    node_spacing_y: "80"
    show_level_text: "true"
    connection_color_locked: "555555"
    connection_color_available: "aaaaaa"
    connection_color_unlocked: "5cb85c"
    node_texture_locked: "eventui:textures/ui/widgets/mission_icon.png"
    node_texture_available: "eventui:textures/ui/widgets/mission_icon.png"
    node_texture_partial: "eventui:textures/ui/widgets/mission_icon_in_progress.png"
    node_texture_maxed: "eventui:textures/ui/widgets/mission_icon_completed.png"
    hover_animation: "zoom_in"
    hover_animation_intensity: "1.08"
    hover_sound: "minecraft:entity.experience_orb.pickup"
    hover_sound_volume: "0.3"
    click_animation: "punch"
    click_sound: "minecraft:block.metal.hit"

Data binding para puntos

Para mostrar los puntos disponibles del jugador, usa data binding en elementos TEXT:

Mostrar puntos disponibles
- id: "points_display"
  type: TEXT
  properties:
    content: "§ePuntos de Combate: §a{{skills.combat_points.available}}"
    shadow: true

Sintaxis disponible:

  • {{skills.<point_type>.available}} — Puntos disponibles
  • {{skills.<point_type>.total}} — Puntos totales ganados

Fuentes de puntos

Las fuentes de puntos se configuran en config.yml. Determinan cómo los jugadores ganan puntos para desbloquear nodos.

Point Type Aliases

Los aliases permiten usar nombres amigables en lugar de IDs internos:

config.yml — aliases
skills:
  point_type_aliases:
    "Puntos de Combate": "combat_points"
    "Puntos de Habilidad": "skill_points"
    "Puntos de Recoleccion": "gathering_points"

Multi-Type Point Distribution

Algunas fuentes pueden otorgar múltiples tipos de puntos simultáneamente usando point_distribution:

config.yml — point_distribution
mob_kill:
  enabled: true
  point_distribution:
    Puntos de Habilidad: 1
    Puntos de combate: 1
    gathering_points: 0.5
Si se usa point_distribution, este sobrescribe point_type y base_points.

Fuentes disponibles

Fuente Descripción
xp_conversion Convierte niveles de experiencia en puntos
mob_kill Otorga puntos al matar mobs
player_kill Otorga puntos al matar jugadores
block_mine Otorga puntos al minar bloques
fishing Otorga puntos al pescar
crop_harvest Otorga puntos al cosechar cultivos
animal_breed Otorga puntos al criar animales
event_complete Otorga puntos al completar eventos
objective_complete Otorga puntos al completar objetivos
playtime Otorga puntos por tiempo de juego

Bukkit Tag Support

Las fuentes de puntos soportan tags de Minecraft para agrupar múltiples entidades/bloques:

Usar tags
mob_kill:
  allowed_mobs:
    - minecraft:zombie
    - "#minecraft:bosses"

block_mine:
  allowed_blocks:
    - minecraft:diamond_ore
    - "#minecraft:logs"

Sintaxis: #minecraft:tag_name
