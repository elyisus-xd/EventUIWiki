## Recording Guidelines

- **Duration:** 3-5 seconds maximum per GIF
- **Frame rate:** 60 FPS for smoothness
- **Crop:** Crop to relevant area only
- **Format:** GIF (optimize with ezgif.com or similar)
- **Size:** Keep under 2MB when possible

## Upload Instructions

1. Record the GIF using OBS Studio or similar
2. Optimize the GIF to reduce file size
3. Upload to Giphy (giphy.com/upload)
4. Copy the direct link (media.giphy.com/media/...)
5. Update the Giphy URL in this file
6. Add the demo-gif component to the corresponding HTML page
